# Threat Analyzer (Python)

## Описание проекта

Данный проект представляет собой простой инструмент анализа угроз информационной безопасности, реализованный на языке Python.

Скрипт анализирует события сетевой безопасности из логов Suricata и проверяет подозрительные IP-адреса через API сервиса VirusTotal.

Цель проекта — показать базовую логику работы систем мониторинга безопасности (SOC):

- сбор данных
- анализ событий
- выявление угроз
- простое реагирование
- формирование отчёта и визуализации

# Источники данных

В проекте используются два источника данных:

## 1. Логи Suricata

Логи Suricata содержат события сетевой безопасности:

- IP источника
- IP назначения
- сигнатуру атаки
- категорию события
- уровень критичности (severity)

Логи используются для выявления подозрительных IP-адресов.

---

## 2. API VirusTotal

VirusTotal используется для проверки IP-адресов на наличие вредоносной активности.

Скрипт отправляет запросы к API VirusTotal и получает:

- количество malicious обнаружений
- количество suspicious обнаружений

---

# Логика работы скрипта

Скрипт выполняет следующие этапы:

1. Загружает логи Suricata из файла `suricata_logs.json`.
2. Анализирует данные с помощью библиотеки **pandas**.
3. Определяет IP-адреса с наибольшим количеством событий.
4. Проверяет несколько IP через **VirusTotal API**.
5. Если обнаружена потенциальная угроза:
   - выводится предупреждение
   - имитируется блокировка IP.

---

# Реагирование на угрозы

Если обнаружено:

- malicious IP в VirusTotal
- высокий уровень severity в логах

скрипт выводит сообщение:

```
[ALERT] Возможная угроза! IP 192.168.1.10 -> имитация блокировки
```

Реальная блокировка не выполняется — используется имитация.

# Настройка API ключа VirusTotal

Перед запуском необходимо указать API ключ.

Windows:

```bash
set VT_API_KEY=ВАШ_API_KEY
```

Linux / macOS:

```bash
export VT_API_KEY=ВАШ_API_KEY
```
